Um site estático sem build, sem framework e sem desculpa para ser lento

Formato · HTML + CSS + JS puro · Hospedagem: GitHub Pages

Resumo

Este site é um experimento de engenharia deliberadamente simples: cada artigo é um arquivo HTML isolado, buscado sob demanda e injetado numa única página-casca. Não há bundler, não há node_modules, não há etapa de build — só arquivos estáticos que o navegador entende de cara. O resultado é um "livro" onde cada aba da barra lateral é um capítulo, carregado em milissegundos e navegável por URL.

1. Por que esse formato existe

A maioria dos geradores de blog estático resolve um problema que este site não tem: milhares de páginas, taxonomias, RSS, busca full-text. Aqui o objetivo é outro — um punhado de artigos técnicos, publicados com git push e nada mais. Um framework de build para isso seria como levar um caminhão para comprar pão.

A arquitetura, então, é a mais direta possível: index.html é a casca (sidebar + área de conteúdo); cada artigo vive em /artigos/*.html como um fragmento solto, sem <html> nem <head> próprios; e um roteador em Vanilla JS busca o fragmento certo e o injeta na casca, sincronizando o hash da URL para que o botão voltar do navegador e o F5 continuem funcionando.
